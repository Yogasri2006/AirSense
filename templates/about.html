About AirSense

Problem Statement

Air pollution changes with pollutant concentrations, weather and time. AirSense uses historical air-quality observations and machine learning to analyze these patterns and predict PM2.5.

Objectives

  • Assess and clean air-quality data.
  • Perform EDA and feature preparation.
  • Compare four regression algorithms.
  • Select the best model using RMSE and R².
  • Provide a usable PM2.5 prediction web application.

Technology

Python, Flask, Pandas, NumPy, Scikit-learn, Joblib, HTML, CSS, JavaScript and Chart.js.
